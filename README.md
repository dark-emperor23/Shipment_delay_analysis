#  Supply Chain Optimization Project

##  Overview
This project focuses on **analyzing and optimizing supply chain performance** through data-driven insights and predictive modeling. The goal is to build an efficient, end-to-end pipeline that can handle data preprocessing, model training, and evaluation to improve decision-making in logistics and operations.

The notebook (`Supply_Chain_Project.ipynb`) demonstrates how machine learning can be leveraged to identify trends, forecast demand, and optimize resource allocation within a supply chain network.

---

##  Project Workflow
1. **Data Collection & Cleaning**
   - Import and inspect raw supply chain data
   - Handle missing values, outliers, and categorical encoding

2. **Feature Engineering**
   - Create meaningful features to capture business dynamics
   - Scale and transform numerical attributes for model readiness

3. **Model Development**
   - Train multiple regression and predictive models
   - Use a unified `Pipeline` approach for cleaner workflow
   - Perform hyperparameter tuning via `GridSearchCV`

4. **Model Evaluation**
   - Compare models based on key metrics:  
     - Mean Absolute Error (MAE)  
     - Root Mean Squared Error (RMSE)  
     - R² Score  
   - Identify the best-performing model for deployment
